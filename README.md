## Workflow 1: Form Submission → Google Sheets + Gmail Notification

### 🔧 What This Workflow Does
When someone submits a form, this automation:
1. **Captures the form data** automatically
2. **Appends a new row** in Google Sheets with the submitted data
3. **Sends a Gmail notification** instantly

### 🛠 Tools Used
- n8n (automation platform)
- Google Sheets
- Gmail

### 💡 Use Case
Perfect for:
- Lead collection forms
- Contact us forms
- Event registrations
- Survey responses
